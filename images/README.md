# Dashboard Screenshots Directory

This directory stores visual assets and interface screenshots for the Automated Resume Screening Tool.

## Recommended Image Filenames

When capturing application screenshots from the Streamlit web dashboard, save them using the following standardized filenames to automatically link with the main project documentation:

1. `dashboard_overview.png` - Main dashboard view showing the cohort summary metrics, review tier badges, and candidate leaderboard.
2. `candidate_audit.png` - Detailed candidate profile view illustrating component point contributions and matched/missing skill tags.
3. `analytics_charts.png` - Analytics tab displaying score distribution histograms and review category proportions.
4. `report_exports.png` - Report download interface displaying CSV and HTML report generation options.

## Capture Instructions

1. Launch the application: `streamlit run main.py`
2. Run candidate screening against the sample dataset or uploaded resumes.
3. Capture the browser window using your operating system screenshot tool (e.g., Windows Snipping Tool: `Win + Shift + S`).
4. Save the image files directly into this directory (`images/`).
