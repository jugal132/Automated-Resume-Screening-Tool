================================================================================
JOB TITLE: Junior Python Developer
================================================================================

JOB SUMMARY
We are seeking an enthusiastic, detail-oriented Junior Python Developer to join our software engineering team. In this entry-level role, you will contribute to backend service development, data processing workflows, and relational database management under the mentorship of senior engineers. We value foundational problem-solving, clean coding practices, and an eagerness to learn modern Python frameworks and software engineering standards.

RESPONSIBILITIES
- Write modular, clean, and well-documented Python code for backend services and automated data tasks.
- Design, write, and optimize relational database queries and schemas using SQL.
- Manipulate, clean, and validate structured tabular datasets using Pandas.
- Maintain code versioning, branch hygiene, and collaborative workflows using Git and GitHub.
- Assist in developing and testing RESTful APIs to integrate internal and external application components.
- Write unit tests and participate in code reviews to maintain software quality and reliability.
- Collaborate with cross-functional team members to diagnose and troubleshoot application issues.

REQUIRED TECHNICAL SKILLS
- Python: Strong grasp of core Python syntax, standard library, data structures (lists, dicts, sets, tuples), and object-oriented principles.
- SQL: Practical ability to write and understand relational queries (SELECT, JOIN, WHERE, GROUP BY, aggregations).
- Pandas: Foundational experience with DataFrame manipulation, data filtering, missing value handling, and transformation.
- Git: Working familiarity with distributed version control workflows, commits, branching, merging, and remote repository collaboration.

PREFERRED TECHNICAL SKILLS
- NumPy: Experience with numerical operations, multi-dimensional arrays, and vectorized computation.
- FastAPI / Flask: Exposure to developing lightweight backend web services and routing microservices.
- REST APIs: Knowledge of HTTP methods (GET, POST, PUT, DELETE), status codes, request/response serialization, and API design.
- PostgreSQL / SQLite: Practical familiarity with relational database management systems and ORM tools (e.g., SQLAlchemy).
- Unit Testing: Understanding of automated software testing principles using frameworks such as unittest or pytest.
- Scikit-learn: Basic familiarity with machine learning preprocessing pipelines or data science concepts.

EXPERIENCE REQUIREMENTS
- 0 to 1 years of software development experience with Python.
- Practical experience may be demonstrated through internships, academic coursework, capstone projects, personal coding initiatives, open-source contributions, or professional employment.
- Prior formal full-time employment is not an absolute prerequisite; demonstrable project evidence of coding proficiency is welcomed and valued.

EDUCATION
- A Bachelor's degree or Associate degree in Computer Science, Information Technology, Software Engineering, Data Science, or a related quantitative discipline is preferred.
- Equivalent practical experience, coding bootcamp training, or demonstrable portfolio projects will be considered equally. Lack of a specific degree is not an exclusionary barrier.

RELEVANT PROJECT EXPERIENCE
Candidates can highlight evidence of technical capability through projects such as:
- Backend web APIs or microservices developed in Flask or FastAPI.
- Relational database management systems with schema design and query execution.
- Data ingestion, cleaning, transformation, or automated reporting pipelines built with Pandas and NumPy.
- Scripting tools or utilities showcasing unit testing, regular expressions, or file I/O operations.
- Open-source contributions or collaborative team repositories managed on Git/GitHub.
